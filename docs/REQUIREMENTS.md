# 原始需求

> 这是项目最初的需求记录，保留原文以便后来者理解设计取舍。实际实现与当前界面以 README 与代码为准。

软件名：补学习（最初名为助学宝）

用户画像：高中生

功能：

将用户上传的错题，或者试卷进行分析，分析其中错误的具体知识点以及思考方式，给出建议的学习方向和思考方式以相关的教学视频和文章链接为主，不给具体的知识和思考方式。记录每一次用户上传的错题和试卷以及其分析乃至给出的建议，按照科目分类记录上传的具体时间科目内按照记录时间排序。将用户每一科错误的具体统计并整理成图表，将简单易得分的常错知识点放前面困难知识点放中间，最后放偶尔错误知识点。练习功能，题目以相关知识点的真题为主网上找的题目为主实在找不到就ai自己出，练习分为单题练习和多题练习，多题练习询问用户想要一次做几道题，在用户上传答案或者点击不会之前不显示答案，用户上传答案之后给出答案分析，找出用户错误，正确则给出鼓励，并询问是否继续练习，真题给出具体的试卷网上题给出题目链接。错题分析完给用户一个直达练习的按键。点击知识点出现两个按键学习和练习跳转相关板块不点这两个键则返回。分为三个板块学习练习复习。ai用api，给出获取教程。
